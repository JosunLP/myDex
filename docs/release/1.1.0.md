app icons”. Contents: `CHANGELOG.md`, section 1.1.0.

      changed, fixed, security; new empty “Unreleased”.
- [x] `apps/pokedex/pubspec.yaml`: `1.1.0+101000` (Android `versionCode` 101000 > 100000).
- [x] `appVersion` 1.1.0 (shown under “More” and on the license page).

- [x] Release workflow checks that the tag matches `pubspec.yaml` and the CHANGELOG.

## After merging (needs repository access)
1. Wait for CI on `main` (including the APK, Windows, macOS and iOS builds).
2. If the merge date is not 2026-11-26: adjust the date in the CHANGELOG heading and the
   AppStream `<release>` in a small follow-up commit (`apps/pokedex/test/version_test.dart`
   checks both).
3. Tag and push:
   ```sh
   git checkout main && git pull
   git tag v1.1.0 && git push origin v1.1.0
   ```
4. The “Release” workflow builds the packages and creates the draft release. The signing secrets
   from `first-release.md` must be present.
5. Acceptance on GrapheneOS with the draft APK (`grapheneos-acceptance.md`); record the result in
   its log, in particular the new steps 4a–4e and the update over 1.0.0 (install over the
   existing app: collection, teams and settings are kept).
6. Desktop spot checks from the draft: Linux tarball shows the window icon; macOS zip contains
   `myDex.app`; Windows `.exe` shows the new icon and version 1.1.0 in its properties.
7. Publish the draft release.
