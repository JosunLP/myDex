# 0005 – Fünf Verfügbarkeitszustände

Status: angenommen

## Entscheidung
Spielabhängige Aussagen tragen einen von fünf Zuständen: bestätigt verfügbar, bestätigt nicht
verfügbar, nicht anwendbar, unbekannt, noch nicht recherchiert.

## Konsequenzen
Fehlende Daten erscheinen in der UI als Datenlücke („noch nicht recherchiert“), nie als
„nicht verfügbar“. Abdeckungsberichte zählen die Zustände je Spiel und Bereich.
