# Linux desktop integration

Installed by `flutter build linux` into `bundle/share/` so that packagers (Flatpak, distro
packages, AppImage) can copy it into the system prefix:

- `applications/io.github.josunlp.mydex_app.desktop` – launcher entry
- `metainfo/io.github.josunlp.mydex_app.metainfo.xml` – AppStream metadata (software centres)
- `icons/hicolor/<size>/apps/io.github.josunlp.mydex_app.png` – icons, generated by
  `tool/brand/generate_icons_test.dart`

The window icon is also loaded from `bundle/data/app_icon.png`, so the plain tarball shows the
right icon without installation.
